## Setup

**Important:** Die benötigten NetCDF-Dateien liegen auf meinem PC. Um das Projekt zu nutzen:

1. Ändere einfach den **Dateipfad** in den Jupyter Notebooks zu deinem lokalen Verzeichnis
2. Stelle sicher, dass die `.nc`-Datenfiles im richtigen Ordner liegen
3. Run it 🏃‍♂️

Beispiel:
```python
# Ändere diesen Pfad zu deinem lokalen Setup
data_path = "/dein/pfad/zu/den/nc/dateien/"
```
